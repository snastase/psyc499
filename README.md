# PSYC 499: Neural and Cognitive Data Science
PSYC 499: Neural and Cognitive Data Science

This repository accompanies the USC course "Neural and Cognitive Data Science" created by Samuel A. Nastase ([course website](https://snastase.github.io/teaching/psyc499)). The `labs/` folder contains Jupyter Notebooks comprising the interactive lab exercises and the `readings/` folder contains PDFs for the optional readings.
